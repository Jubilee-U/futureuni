# 🚀 FutureUni

**Closing the Digital Gap** — a digital media agency website helping brands grow through powerful digital solutions, from stunning designs to high-converting websites and viral video content.

🔗 **Live Demo futureuni.org

---

## ✨ Features

- Hero section with agency positioning and CTAs
- Services showcase (Social Media Design, Landing Pages, Web Design, Video Ads) with tiered pricing
- Dual currency toggle (₦ / $)
- Training programs section with course pricing
- Filterable portfolio grid by category
- Client testimonials and FAQ accordion
- Multi-field project intake form with file upload
- Fully responsive design

---

## 🛠️ Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
